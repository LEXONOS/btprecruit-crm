NOVALEM - Espace "Sites Internet" (creation de sites web)
==========================================================

Cette archive s'extrait A LA RACINE du depot btprecruit-crm-main.
Les chemins sont deja bons : Git ne verra que les vraies differences.

Le CRM recrutement n'est PAS modifie. Verifie par empreinte : crm-app.js,
crm-auth.js, crm-styles.css, crm.html, sign.html, index.html, jobs.js,
send-email.js et schema.sql sont strictement identiques a l'origine.
Aucune fonction serverless ajoutee (toujours 10 dans /api, limite 12).

LA SEULE ETAPE MANUELLE : la base de donnees
--------------------------------------------
1. Ouvre Supabase > SQL Editor > New query (projet hfdkkdyyhpymrwiqmitn).
2. Colle TOUT le contenu de supabase/sites-schema.sql.
3. Clique Run. Le script est idempotent : rejouable sans risque. Il finit par
   un rechargement du cache API (corrige l'erreur "table not found in schema cache").
   -> A relancer si tu mets a jour depuis une version precedente (ajoute la table
      web_cadrages utilisee par la fiche de cadrage).

Puis pousse sur GitHub et laisse Vercel deployer.
Espace accessible : tuile "NOVALEM Sites" du hub, ou /sites.


LA FICHE DE CADRAGE
-------------------
- Accessible depuis la barre laterale du CRM ("+ Fiche de cadrage") et depuis
  chaque fiche client (bouton "Ouvrir la fiche de cadrage"), pre-remplie.
- Elle enregistre dans Supabase (table web_cadrages), plus dans window.storage.
- Bouton "Envoyer vers le CRM" : cree le client (si besoin) et un devis brouillon
  a partir de la formule et des options cochees.
- Prix des formules alignes sur la plaquette : 390 / 790 / 1190. La fiche d'origine
  affichait 490 / 890 / 1690. Si ces prix-la etaient les bons, il suffit de le dire.


BON A SAVOIR
------------
- Envoi de devis : /api/send-email (inchange), repli mailto.
- Signature eIDAS : lien /sites-sign genere a l'envoi, protege par jeton. Aucune
  fonction serveur ajoutee (RLS + trigger Supabase).
- Devis = contrat : le devis signe "bon pour accord" vaut contrat de prestation
  (12 articles portes automatiquement sur le PDF). PDF devis-contrat + PDF facture.
- Facturation : paiement 100 % a reception de la facture, AVANT mise en ligne.
  Aucun acompte. Une facture emise est inalterable (correction par avoir).
- Espace "Prospection" retire (prospection faite hors outil, sur Google Maps).
- Infos legales et coordonnees de paiement : bloc ENTREPRISE en haut de sites-app.js.
- RLS par defaut : espace partage entre utilisateurs internes. Variante stricte
  par proprietaire disponible en commentaire en bas de sites-schema.sql.
